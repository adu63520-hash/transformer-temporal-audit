# Predictive accuracy and temporal arrangement in Transformers

Code and synthetic experiment results for **Predictive accuracy and temporal arrangement in Transformers: A controlled physical inference study**, by Deli Liu, Xiaoping Zhou, and Yu Li (Beijing University of Civil Engineering and Architecture).

The experiments distinguish prediction accuracy, sensitivity to temporal arrangement, and transfer under changes in forcing. This release includes the original benchmarks and the additional analyses reported in the revised PRL manuscript. The data generators reproduce the inputs locally.

## Repository layout

| Path | Contents |
|---|---|
| `temporal_audit/tasks.py` | Relaxation-chain simulator, tokenisation, interventions, OLS, invariant ridge, and evaluation metrics |
| `temporal_audit/train_tf.py` | Causal Transformer regressor, training, and inference |
| `temporal_audit/experiments/` | Original benchmark, reference estimators, forcing-period transfer, and result aggregation |
| `temporal_audit/experiments/revision/` | Rotation, Deep Sets, quantisation, paired statistics, and repeated transfer evaluations |
| `temporal_audit/plots/` | Final figure generator and original-submission figure generators |
| `results/` | Archived experiment configurations, learning curves, predictions, and metrics |
| `figures/` | Final manuscript figures in vector PDF and PNG |

In filenames, `orig` and `rand` denote fixed and random forcing. `clean`, `time`, and `full` denote ordered, hour-shuffled, and fully permuted training inputs. Each original run JSON contains its configuration, learning curve, final ID and OOD metrics, and ordered-input predictions.

## Setup

Use Python 3.10 or later. Run all commands below from the repository root. A CUDA GPU is recommended for Transformer training. The final figure generator requires Times New Roman installed locally.

```sh
python -m pip install -r requirements.txt
python -m temporal_audit.experiments.run_all --smoke --results-dir reproduced_revision/smoke
```

## Original benchmark

The commands below write to a separate directory. The training driver skips completed files for the same training budget, so a stopped run can be resumed.

```sh
python -m temporal_audit.experiments.anchors --results-dir reproduced_revision/benchmark
python -m temporal_audit.experiments.run_all --results-dir reproduced_revision/benchmark --steps 3000
python -m temporal_audit.experiments.run_all --results-dir reproduced_revision/benchmark --long
python -m temporal_audit.experiments.summarise_runs --results-dir reproduced_revision/benchmark
python -m temporal_audit.experiments.cue_conflict --results-dir reproduced_revision/transfer
```

The 3,000-update grid has three training seeds per forcing and input condition plus the token-only variants. The 12,000-update follow-up has one clean run and three hour-shuffled runs. The transfer command trains one seed-0 checkpoint per regime when absent and saves it under the selected results directory's `ckpt/` subdirectory. It can also evaluate existing checkpoints using `--checkpoints PATH`.

The corresponding archived outputs are `results/anchors.json`, `results/runs/`, `results/summary.json`, `results/cue_conflict.json`, and `results/runs_ckpt/`. Checkpoint weights are generated locally.

## Revision experiments

| Module in `temporal_audit.experiments.revision` | Reproduces |
|---|---|
| `arrangement_controls` | Absolute and paired prediction changes under shuffling, successor ranking, and analytic rotation control |
| `rotation_gru` | Learned rotation control with three training seeds per regime |
| `paired_accuracy_and_deep_sets` | Paired error intervals, Deep Sets, OLS resolution sweep, and channel-pairing ablation |
| `quantisation_amplitude` | Signal-amplitude control at fixed quantisation |
| `quantisation_rollout` | Quantisation-aware rollout estimator |
| `forcing_noise_transfer` | Forcing-period transfer on ten fresh noise batches per period with fixed checkpoints |

Each archived JSON in `results/revision/` has the same stem as its module. These commands reproduce the analyses using the archived benchmark results and local checkpoints.

```sh
python -m temporal_audit.experiments.revision.rotation_gru reproduced_revision/rotation_gru.json
python -m temporal_audit.experiments.revision.quantisation_amplitude reproduced_revision/quantisation_amplitude.json
python -m temporal_audit.experiments.revision.quantisation_rollout reproduced_revision/quantisation_rollout.json
```

If the checkpoints were generated by the transfer command above, use:

```sh
python -m temporal_audit.experiments.revision.arrangement_controls reproduced_revision/arrangement_controls.json --checkpoints reproduced_revision/transfer/ckpt
python -m temporal_audit.experiments.revision.paired_accuracy_and_deep_sets reproduced_revision/paired_accuracy_and_deep_sets.json --checkpoints reproduced_revision/transfer/ckpt
python -m temporal_audit.experiments.revision.forcing_noise_transfer reproduced_revision/forcing_noise_transfer.json --checkpoints reproduced_revision/transfer/ckpt
```

These commands default to `results/` for archived inputs. Use `--results-dir reproduced_revision/benchmark` to read newly generated benchmark outputs instead. If omitted, the checkpoint path defaults to the selected results directory's `ckpt/` subdirectory.

Results can vary when models are retrained on different hardware or PyTorch versions. The forcing-noise transfer experiment repeats evaluation across new input draws for each fixed checkpoint. Variation across these batches describes test forcing variability. The earlier frozen-language-model protocol discussed in the paper is outside this release.

## Figures

The final figures can be regenerated without training, using the archived summary:

```sh
python -m temporal_audit.plots.make_figures results/summary.json reproduced_revision/figures
```

The original-submission figures are reproducible through `temporal_audit.plots.initial_make_paper_figures` and `temporal_audit.plots.initial_make_schematic`. They write to `figures/initial/` by default.
